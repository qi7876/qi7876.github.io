每周3-4练，练一休一，每3个训练日过一遍全身。  

## Day 1：胸+三头+腹  
### 热身动作：  
胸椎活动度、肩袖激活、前锯肌激活、肘关节预热、身体整体激活。  
### 正式训练：  

| 动作       | 组数       | 备注           |
| -------- | -------- | ------------ |
| 器械夹胸     | 3x12-15  |              |
| 杠铃/器械卧推  | 2x5 4×10 | RPE 7，过渡到6x5 |
| 哑铃/器械上斜推 | 4×12     | RPE 8.5      |
| 肩胛俯卧撑    | 3x力竭     |              |
| 龙门下压     | 4×12     | RPE 8.5      |
| 龙门卷腹     | 2×20     |              |

### 拉伸放松：  
松解、活动度。  

## Day 2：背+二头+脊柱  
### 热身动作：  
手腕热身、肩胛激活、胸椎活动度、脊柱活动度、髋铰链激活、泡沫轴梳理、弹力带激活。  

### 正式训练：  

| 动作     | 组数      | 备注      |
| ------ | ------- | ------- |
| 引体向上   | 4x10    |         |
| 龙门器械平拉 | 4x12    | RPE 8.5 |
| 高位下拉   | 4x12    | RPE 8.5 |
| 哑铃靠墙划船 | 2x15    | RPE 8.5 |
| 罗马尼亚硬拉 | 4×12-15 | RPE 8.5 |
| 杠铃弯举   | 4x12    |         |


### 拉伸放松：  
泡沫轴、脊柱滚动。  

## Day 3：腿+肩  
### 热身动作：  
足背屈激活、髋关节活动度激活、筋膜梳理。  

### 正式训练：  

| 动作     | 组数     | 备注    |
| ------ | ------ | ----- |
| 单腿硬拉   | 3×12   |       |
| 杠铃深蹲   | 3×8-10 | RPE 7 |
| 保加利亚深蹲 | 3×12   | RPE 7 |
| 高脚杯深蹲  | 3×12   | RPE 7 |
| 哑铃推举   | 4×12   | RPE 7 |
| 单手侧平举  | 4×15   |       |


### 拉伸放松：  
筋膜球、泡沫轴、梳理。
